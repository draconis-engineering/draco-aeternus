# Draco Aeternus | Draconis World Catastrophe Preparation Assets

## What is this?

**D.A.** is a suite of products (*assets*/*nodes*) created by Draconis to prepare for world-altering catastrophes. They are designed following a set of principles, all of which are outlined below. All assets are entirely open-source and free to download, modify, and use.

## The 10 Design Principles

All assets/nodes should...

1) ...be easily transportable.
2) ...be easy to repair and maintain.
3) ...be self-contained and operate independently.
4) ...be easy to both learn how to use and to use effectively.
5) ...function equally well as a single unit as it would as a multi-node system.
6) ...follow the principles of least complexity and/or least concern (Law of Demeter).
7) ...not be built with, or rely on, any proprietary, closed-source, or other special/non-standard technologies.
8) ...not rely on any external dependencies or services, such as Wi-Fi, Cloud Services, or power grids. (GNSS satellites are used, but not relied on 100%.)
9) ...not be reliant on any single point of failure. Any failure should be isolated to a single node or component, and the system should continue to function normally.
10) ...be durable, resilient, and able to withstand extreme conditions. They should also meet/exceed the relevant standards such as waterproofing (normally >= IPX7), dustproofing, and other safety standards.
