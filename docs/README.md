# Draco Aeternus | Draconis World Catastrophe Preparation Assets

## What is this?

**D.A.** is a suite of products (*assets*/*nodes*) created by Draconis to prepare for world-altering catastrophes. They are designed following a set of principles, all of which are outlined below. All assets are entirely open-source and free to download, modify, and use.

### Nomenclature

**Nodes** are a subset of **Assets**, with the capability to communicate with each other as well as functioning independently.

## Design Principles

- It should be easily transportable.
- It should be easy to repair and maintain.
- It should be self-contained and operate independently.
- It should be easy to both learn how to use it and to use it effectively.
- It should function equally well as a single unit or as a multi-node system.
- It should follow the principles of least complexity and/or least concern (Law of Demeter).
- It should not be built or rely on any proprietary, closed-source, or *special* technologies.
- It should not rely on any external dependencies or services, such as Wi-Fi, Cloud Services, or power grids.
